## Overview

**Trek Guardian** is an IoT + ML health monitor for mountaineers. The ESP8266 device reads SpO2, heart rate, altitude, temperature, humidity, and GPS. Risk is scored on-device by a **distilled Decision Tree** exported from a research-grade training pipeline.

The ML task is **early hypoxia warning**: features at time *t* predict SpO2 severity in a **future** horizon — not a circular re-label of the same static thresholds.

**Training data (real, not synthetic):**
- [Harespod](https://www.nature.com/articles/s41597-024-03065-x) — Scientific Data 2024
- [HAPP](https://www.nature.com/articles/s41597-025-06508-1) — Scientific Data 2025

Chamber physiology ≠ Himalayan AMS field labels. See [`dataset/README.md`](dataset/README.md).

## Features

- Continuous SpO2, heart rate, altitude, temp/humidity, GPS
- **Early-warning ML** with subject-wise GroupKFold + naive SpO2 baseline comparison
- On-device distilled tree using EWMA / slope features
- Cloud GBM scoring via `POST /predict`
- Offline captive portal (`TrekGuardian_Rescue`) when WiFi is down
- LED + buzzer local alerts

## ML pipeline

```bash
cd ml_model
pip install -r requirements.txt
python download_datasets.py          # HAPP + Harespod (Figshare)
python preprocess.py                 # → dataset/processed/vitals_1hz.*
python train_model.py                # GroupKFold GBM + distilled tree
python evaluate.py                   # metrics + confusion matrices
python export_rules.py               # overwrites firmware/ml_model.cpp
```

**Labeling:** future-window SpO2 severity (~90s ahead).  
**Baseline:** current SpO2 thresholds only.  
**Deploy:** Decision Tree on firmware features (`altitude`, `spo2`, `heartRate`, EWMA, slopes).  
**Cloud:** `HistGradientBoostingClassifier` on the full feature set.

Artifacts: `trek_guardian_gbm.pkl`, `trek_guardian_model.pkl`, `ml_model/metrics/training_summary.json`.

## IoT server

```bash
cd iot_server
pip install flask joblib scikit-learn numpy
python alert_api_example.py
```

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/alert` or `/api/alerts` | Device emergency payload |
| POST | `/predict` | Cloud GBM risk + confidence |
| GET | `/health` | Liveness / model readiness |

Example predict body:

```json
{
  "spo2": 91,
  "altitude": 4200,
  "heartRate": 118,
  "spo2_ewma": 92.1,
  "hr_ewma": 115.0,
  "spo2_slope": -0.08,
  "hr_slope": 0.4
}
```

## Risk tiers (label ontology)

Used for **future** SpO2 severity during training; on-device output uses the distilled tree.

| Level | Future SpO2 cue (training labels) |
|-------|-----------------------------------|
| CRITICAL | future min SpO2 &lt; 88 |
| HIGH | future min SpO2 &lt; 90 |
| MODERATE | future min &lt; 93 or mean &lt; 94 |
| LOW | otherwise |
